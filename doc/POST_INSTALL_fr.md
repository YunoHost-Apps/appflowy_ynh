IMPORTANT : Le client web (Appflowy-web) restera inutilisable tant que vous ne vous serez pas connecté depuis une application locale. C'est un bug lié à la création de l'espace de travail personnel. Une fois celui-ci créé, vous pouvez très bien n'utiliser que la version web.

1. **Accéder au panneau d'administration**
Le panneau d'administration (Appflowy-Cloud) se trouve à l'adresse https://__DOMAIN__/console/web/login

2. **Utiliser un client de bureau avec votre Appflowy auto-hébergé**
Téléchargez et installez l'application AppFlowy pour votre appareil : https://appflowy.io/downloaded
Ouvrez l'application AppFlowy.
Cliquez sur « Quick Start ».
Allez dans la page `Settings`.
Dans la barre latérale gauche, choisissez `Cloud Setting`.
Sélectionnez `AppFlowy Cloud` comme fournisseur cloud.
Indiquez l'adresse de votre serveur <https://__DOMAIN____PATH__> dans le champ prévu à cet effet.
Cliquez sur Restart pour appliquer les modifications.
Retournez dans la page `Setting`
Dans la barre latérale gauche, choisissez `User`

3. **Se connecter à l'application web AppFlowy**
L'application web (Appflowy-Web) est disponible à l'adresse https://__DOMAIN____PATH__
